# Питомник ALLVIK — керн-терьеры · редизайн (макет)

Одностраничный макет главной страницы https://cairn-allvik.ru/, переработанный
по референсу: тёмная «шоколадная» тема, медные акценты, крупные рукописные
заголовки, нумерация разделов (01–10).

**Бэкенда нет** — это статичный макет: форма не отправляется, все ссылки ведут
на якоря внутри страницы.

## Как открыть

Просто открыть `index.html` в браузере (интернет нужен только для шрифтов
Google Fonts — Montserrat и Caveat).

## Структура

```
index.html          — разметка всех секций
css/style.css       — вся стилизация (переменные цветов в :root)
js/main.js          — меню, шапка, reveal-анимации, лайтбокс, демо-форма
assets/img/         — фото питомника (скачаны с cairn-allvik.ru)
```

## Секции (как в референсе)

| №   | Блок                                             |
|-----|--------------------------------------------------|
| —   | Шапка + hero с фото и рукописным «Керн-терьеры»  |
| 01–04 | Медные карточки-навигация (щенки, собаки, порода, контакты) |
| 05  | «Питомник» — тёмная секция о питомнике с титулами |
| 06  | «О породе» — рамка с фото и тремя пунктами        |
| 07  | «Чемпионы» — кобели и суки                        |
| —   | Новости (2 карточки)                              |
| 08  | «Щенки родились!» баннер + пометы                 |
| 09  | Фотогалерея (masonry + лайтбокс)                  |
| 10  | Контакты и форма                                  |

## Что менять чаще всего

- Цвета: переменные `--bg*`, `--copper-*` в начале `css/style.css`.
- Тексты собак/пометов: блоки `.dog-card` и `.litter-card` в `index.html`.
- Фото: заменить файлы в `assets/img/` (имена сохранять).
- Скорость reveal-анимаций: `@keyframes rise` и `--rd` в `js/main.js`.
